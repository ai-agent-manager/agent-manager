# HLD Architecture Generator Skill

This skill generates comprehensive High Level Design (HLD) architecture documents from your project requirements, technical constraints, and existing codebase context.

## Usage

Run this skill from your AI coding tool (Claude Code, Windsurf, Cursor, or GitHub Copilot):

```
Generate an HLD for the payment service based on the Jira epic PAY-123
```

The skill will analyse your requirements and produce a structured HLD document including context diagrams, container breakdowns, and deployment topology.
