# TDD Frontend Generator Skill

This skill generates frontend components following a strict TDD workflow — failing tests first, then minimal implementation to make them pass.

## Usage

Run this skill from your AI coding tool:

```
Generate a TDD component for a user profile card based on story PROJ-456
```

Supported frameworks: React (Vitest/Jest), Angular (Karma/Jest), Vue (Vitest), Svelte (Vitest, experimental).
