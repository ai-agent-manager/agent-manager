# REST API Generator Skill

This skill generates complete REST API implementations from high-level requirements or existing data models.

## Usage

Run this skill from your AI coding tool:

```
Generate a REST API for managing customer orders with CRUD endpoints
```

Customise output by placing a `.rest-api-gen.yaml` in your project root to specify the target framework, database adapter, and authentication strategy.
