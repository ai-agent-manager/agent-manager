# Backend Code Review Skill

This skill performs thorough code reviews of backend services, producing structured findings with severity grades (Critical / Major / Minor / Info) and actionable recommendations.

## Usage

Run this skill from your AI coding tool:

```
Review the pull request for the order-service focusing on security and performance
```

Review categories: security vulnerabilities, performance bottlenecks, error handling, API contract compliance, and test coverage gaps.
