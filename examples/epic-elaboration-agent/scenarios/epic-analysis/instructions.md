You have requirements and materials. Now analyze and break down into epics.

1. Analyze Requirements:
Identify logical epic groupings (8–12 epics typically)
Look for distinct functional areas, user journeys, or system components
Each epic should be: 2–4 sentences, 2–3 weeks effort, 3–8 stories

2. Define Each Epic:
For each epic, create:
Name: Verb + Noun (2–6 words) – e.g., "Implement User Authentication"
Scope: 2–4 sentences describing what's included
Goals:
  Customer Goal: What customer can achieve
  Business Goal: Business outcome or metric
Priority: Must/Should/Could/Won't with justification
KPIs: 3–5 measurable metrics
Assumptions: What we're assuming (needs validation)
Dependencies: Technical, Business, External
Rationale:
  Why this epic exists (business value, customer need, technical necessity)
  Why this priority (MoSCoW justification)
  Why this phase (sequencing rationale)
  Why this scope (scope decisions)

3. Map Dependencies:
Identify which epics depend on which (Epic A must complete before Epic B)
Identify external dependencies (third-party APIs, partner teams)
Determine critical path (longest dependency chain)
Identify parallelizable work

4. Organize into Phases (3–4 phases typically):
Phase 1: Foundation epics (no dependencies, highest priority)
Phase 2–3: Core features (depend on Phase 1)
Phase 4: Nice-to-have (Could-Have priority, can be deferred)
For each phase, explain:
  Which epics are in this phase
  Why these epics are grouped together
  What this phase delivers (value)
  Capacity estimate (story points, weeks)

5. Requirements Traceability:
Create matrix mapping requirements to epics
Ensure 100% coverage (every requirement addressed by at least one epic)
Flag any gaps

6. Identify Open Questions:
What decisions are needed?
What assumptions need validation?
What dependencies need confirmation?

7. Present Summary:
"I've analyzed your requirements and identified [N] epics organized into [N] phases:

Phase 1 (Foundation):
  Epic 1: [Name] – Must Have – [Rationale]
  Epic 2: [Name] – Must Have – [Rationale]

Phase 2 (Core Features):
  Epic 3: [Name] – Should Have – [Rationale]
  …

I'll now create the comprehensive Confluence Epic Break-down Analysis document.
This will take a few minutes."

8. Hand off to Scenario 3 (Confluence Doc Creation)
