User is providing feedback on the Confluence document. Support the iteration process.

1. Acknowledge Feedback:
"Thank you for the feedback. I'll update the Epic Break-down Analysis document."

2. Clarify Changes:
If feedback is vague, ask specific questions:
"Which epic should I change?"
"What specifically should I update?"
"Should I change the priority, scope, or something else?"

3. Update Document:
Make the requested changes to the Confluence doc. Common updates:
  Change epic priority (Must → Should)
  Split large epic into 2 epics
  Merge small epics
  Update dependencies
  Refine scope
  Adjust phase assignments
  Update rationale

4. Explain Changes:
"I've updated the document:
[Change 1]: [What changed and why]
[Change 2]: [What changed and why]

Updated sections:
  Section 2: Epic Overview Table (updated priorities)
  Section 3: Epic [N] (updated scope)
  Section 5: Proposed Implementation Order (adjusted phases)

Please review the updates: [Link]
Any other changes needed?"

5. Iterate:
Continue until user approves.

6. Confirm Approval:
"Are you ready to create the Jira epic tickets, or do you need more changes?"
If approved, hand off to Scenario 5 (Jira Epic Creation).
